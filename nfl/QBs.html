Starting streaks: one row per team’s latest regular-season starting QB, if still on that team’s eligible roster. Counts consecutive team games started at QB, not games played or games with a pass. Missing a start for any reason—including injury, rest, suspension or benching—breaks the streak. Byes do not. Runs carry across seasons, but not across teams. Playoffs and preseason are excluded. “Active” describes the recorded run through the team’s latest completed regular-season game, not a prediction of who will start next.

All-time streaks: recorded runs for today’s 32 franchises, including completed runs and multiple streaks by the same quarterback. Game-level starter history begins in 1950; earlier records are not included. The coverage note above the table identifies any gaps in recent data. “≥” marks a run whose full length is unknown at a coverage boundary. Ranks use the recorded lengths and share places for ties. Relocations and name changes stay with the same franchise; defunct clubs remain separate. The 1987 replacement games count as team games and can break a streak.

Franchise leaders: each quarterback’s longest recorded run with that franchise, ranked within the franchise. Equal best runs by the same QB use the earlier run. Select a team to see its leaderboard. A green row means that run extends through the franchise’s latest completed game, without predicting the next starter.

Tenure: all current roster QBs, including backups and practice-squad/reserve players. Counts consecutive seasons listed with the franchise, including the current season. “Since” is a roster season, not an exact signing date. Missing seasons and intervening franchises reset the stint; short releases/re-signings within a season may not be visible in annual roster history. Team relocations do not reset tenure. Roster status is not a depth-chart ranking.

Checked daily at 1:30 a.m. Eastern (America/New_York), adjusting for daylight saving time. Source updates can lag games and transactions. Each team uses its latest available regular-season roster snapshot, including during bye weeks. Sources: ESPN game-roster starter flags (active runs and 2023 onward), nflverse game dates/results, FiveThirtyEight starter history preserved by nfelo (1950–2022), and nflverse current and historical rosters. The schedule’s primary passer is not used as a substitute for the official starter.
